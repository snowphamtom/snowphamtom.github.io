The Engine

SRAT-20 is a single-header C++20 lock-free queue: a Michael–Scott queue whose nodes and packets are reclaimed through 3-slot hazard pointers, in which every packet carries a residual certificate, admission at the gate is fail-closed, and an execution genome adjusts the engine's own spin and damping parameters through fitness-gated atomic updates.

It is the concurrent realization of the house admission rule: a thing is admitted only if it fits inside what is measured to be there — and what does not fit is refused, without side effects.

Governing invariant · S_H = S_solv ∧ R_H ⇔ (C ≼ I(t)) ∧ (|r_H| ≤ ε_H)
Residual validity · a packet is residual-valid at epoch E when e_p + 1 ≥ E ∧ |r_H| ≤ ε_H — checked before resource ceilings
Resource ceilings · each packet's resource vector (c, m, p, q) must fit under the ceiling packet, component by component
Diagnostic · Φ_H is diagnostic only — it never authorizes admission

Design Invariants

Hazard pointers — 3 slots
Each thread protects the pointers it is using in three hazard slots (MaxHP = 3). Reclamation scans every live slot and frees only what no slot references; the retire threshold is 6.
A residual certificate on every packet
Every OmniPacket carries its certificate — residual_H, epsilon_H, residual_epoch — as first-class fields. The certificate travels with the packet; it is not a side table.
Fail-closed gate
Enqueue stage 1 refuses any packet whose resources exceed the ceiling or whose certificate is stale or out of tolerance. A refused packet is rejected without side effects — nothing is linked, nothing is owed.
Epoch-scoped validity
A single atomic residual epoch modulates all traffic. Once a certificate is invalid at an epoch it remains invalid at every later epoch, so helping that refuses an invalid node can never be wrong later.
Digest binding
On admission, the packet's digest is bound to its resource vector, its kinematics, and its residual before the node is linked into the queue — the commitment and the certificate are one act.
Execution genome
An execution genome (spin_limit, damping, generation) is installed only by a compare-and-swap that carries strictly higher measured fitness. The tuning path cannot bypass the residual gate; mutation happens off the admission decision.

// ─────────────────────────────────────────────────────────────────────────────
// Packet — residual certificate is first-class
// ─────────────────────────────────────────────────────────────────────────────
struct alignas(32) OmniPacket {
    uint32_t c = 0, m = 0, p = 0, q = 0;       // GR-21 resource vector
    float    x = 0, y = 0, z = 0, psi = 0;      // kinematics
    uint64_t digest = 0;

    float    residual_H = 0.0f;
    float    epsilon_H  = 0.01f;
    uint64_t residual_epoch = 0;

    bool residual_ok(uint64_t epoch) const noexcept {
        return residual_epoch + 1 >= epoch &&
               std::abs(residual_H) <= epsilon_H;
    }
    bool resources_ok(const OmniPacket& ceil) const noexcept {
        return c <= ceil.c && m <= ceil.m && p <= ceil.p && q <= ceil.q;
    }
    uint64_t bind(uint64_t prev) const noexcept {
        return prev ^ (uint64_t(c) * p) ^ uint64_t(psi * 1e4f)
                    ^ uint64_t(residual_H * 1e6f);
    }
};
