Recompute any drop, in three steps.

  1. Open the drop and download its files.
  2. Run sha256sum -c SHA256SUMS.txt in the folder — every file must report OK.
  3. Follow the drop's own procedure: the papers show their derivations line by line; the verify drop is a program — run it and compare its output against its published results file.
