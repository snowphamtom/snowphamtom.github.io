REFUSAL FRAME FORMAT · REVISION 1 · MONSTERS INK LLC · 6 OCTOBER 2026 · DOCKET REFERENCE: RFF-1

Status: NEW MATTER — NOT FILED. This is an engineering specification. Patentability requires counsel review and a prior-art search.

RFF-1 is a self-describing code format that unifies two refusal layers. Layer 1 (code): the C(r,N) common-bit refusal-code family — repair-or-refuse decoding. Layer 2 (admission): labeled-lane admission on surviving frames — per-lane admit/refuse; surplus never crosses labels. Refusal propagates: a frame refused at Layer 1 never reaches Layer 2.

The C(r,N) Family

Parameters: r parity rows (r ≥ 2), N message symbols (1 ≤ N ≤ 2^(r−1) − 1). Construction: H is r×N; column j is the j-th binary r-vector (lexicographic by integer value) with bit 0 set and Hamming weight ≥ 2. Every column contains the common bit (row 0).

Proved for every instance (proofs by the common-bit argument):

(a) every single payload spike, any nonzero magnitude → repaired;
(b) every single parity-tail edit → detected, payload intact;
(c) every dual-spike event at distinct columns, any magnitudes/signs → refused;
(d) every same-sign multi-spike event, order ≥ 2 → refused.

Disclosed boundary: adversarial mixed-sign faults of order ≥ 3 can alias (outside the proven fault model).

The proofs transfer to every (r, N) because the pair-sum argument uses only two facts — entries are binary, and every column contains row 0. Any i ≠ j gives H_i + H_j with a 2 in row 0, which no binary column can equal, so no dual-spike syndrome aliases a single.

Decoder behavior. (1) Validate magic and parameters; split payload/parity. (2) Layer 1: syndrome s = Hv′ − t′; classify CLEAN / REPAIRED / TAIL_EDIT / REFUSED (single-column support + uniformity + syndrome-collapse verification). (3) If REFUSED → return immediately; the frame never reaches admission. (4) Layer 2: aggregate each lane's symbols to an integer figure; compare against the interior capacity per label — a missing label is a refusal; negative headroom is a refusal, lane named; surplus is held, never applied across labels. (5) Return frame status, trusted payload (if not refused), per-lane rows, and the overall admission decision.
