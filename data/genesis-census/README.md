# GENESIS Census — Open Data

Taylor Heller / Monsters Ink LLC — published 2026-10-22.

The complete measured census of the 48-node GENESIS system: the odd masks
3..97, every pair classified, every door enumerated. Generated by
`core_engine_proof.py` (CORE ENGINE PROOF SEAL 34/34) and exported verbatim;
every figure below was recomputed at export.

## The census (measured)

- **48 nodes** — the odd masks 3, 5, …, 97
- **1,128 pairs**, classified: **944 DOOR · 124 ALIAS · 60 NEVER**
- **7,140 doors** — quadruples (a, b, c, d) with a + b = c + d, the exact
  door rule (a + b − c = d, popcount identity, (a^b) == (c^d))
- ALIAS ⟺ Hamming distance 1 (124/124, biconditional); distance distribution
  {1: 124, 2: 282, 3: 352, 4: 253, 5: 100, 6: 17}
- **83 distinct pair sums** (midpoints), range 16..184; every door's two
  pairs share one midpoint
- **17 complement pairs** with a + b = 128, all DOOR

## Files

- `pairs.csv` — all 1,128 pairs: a, b, Hamming distance, class, doors on pair
- `doors.csv` — all 7,140 doors with their shared pair sum
- `W_pair_adjacency.csv` — the 48×48 pair-adjacency matrix (doors per pair)
- `midpoints.csv` — the 83 pair sums with door counts
- `spectra.txt` — W and T spectra (W: λmax 299.358, λmin −129.871 ×3,
  Σλ² = 191,808; T: λmax 598.650, λmin −86.262, Σλ² = 685,584)
- `SHA256SUMS.txt` — checksums for every file in this folder

## Scope

This is a data publication: the census is exact and independently
recomputable from the door rule. Spectral-class measurements on these
operators (r-ratio statistics) are published separately with their own
scope notes.
