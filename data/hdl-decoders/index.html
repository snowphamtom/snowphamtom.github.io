V4 Sidon — Verilog Decoders (Both Matrices)

Taylor Heller / Monsters Ink LLC. Two synthesizable repair-or-refuse decoders — the F₆₄ spec set and the fully closed GF(2⁷) set — sharing one architecture: syndrome calculator + admission classifier (0 → CLEAN, ±column → REPAIR, ±axis → TAIL, anything else → REFUSE).

Verified: exhaustive RTL simulation against an independent golden model — 143,005 vectors per decoder (every signed pattern of weight ≤ 3, plus tails): PASS, 0 errors, both decoders. Yosys generic synthesis: 5,055 and 5,236 cells. No Fmax and no throughput figure is claimed — none has been measured against a target library.
