# V4 Sidon over GF(2⁷) — the Corrected Record and the Fully Closed Set

Taylor Heller / Monsters Ink LLC — published 2026-10-22.

Two 48-mask sets on the GF(2⁷) curve (x³ << 7) | x, polynomial 0x83
(x⁷ + x + 1, primitive), measured exhaustively in the unit-amplitude
integer model. `battery.py` in this folder reproduces every figure below
from the two CSVs.

## seed6 — the as-built set, and the correction

The package that circulated as "V4_Sidon_69184_CERTIFIED" claimed all
69,184 signed weight-≤3 triple syndromes distinct, "0 alias." Independent
recomputation (2026-10-20, two counting methods) measured otherwise:

- Pair level closed, exactly as claimed: 48 distinct nonzero masks;
  row sums [31, 25, 22, 28, 20, 26, 27, 28, 23, 25, 25, 26, 22, 19],
  347 bits; min Hamming distance 2; XOR pair sums 1,128/1,128 distinct;
  integer ++ 1,128/1,128; ordered +− 2,256/2,256.
- Triple level NOT closed: +++ 17,286 of 17,296 distinct (10 collisions);
  ++− 51,798 of 51,888 (90 collisions); 10 triple syndromes equal a pair
  syndrome. **Distinct triple syndromes: 69,084 of 69,184.**
- The 110 aliases are generated by exactly 11 identities: one five-tuple,
  (19,38,41) = (36,45), and ten six-tuples.

**The label "69184 CERTIFIED" is withdrawn.** The full correction is
`correction_2026-10-22.md` in this folder.

Five columns of seed6 swapped to reserve curve points (indices
8, 12, 16, 28, 36 → 3996, 1167, 7829, 4626, 9494), verified exhaustively

- Row sums [28, 27, 23, 26, 23, 24, 26, 28, 23, 25, 27, 26, 23, 19],
  348 bits; min Hamming distance 2.
- XOR pair sums 1,128/1,128; integer ++ 1,128/1,128; ordered +− 2,256/2,256.
- Triples +++ 17,296/17,296 distinct; ++− 51,888/51,888 distinct;
  **total 69,184 of 69,184 distinct triple syndromes**; no syndrome shared

  syndrome, a single, zero, or an axis vector.
- 79 curve points remain unused in the reserve pool.

## Decoder acceptance — three models, stated plainly

A weight-3 pattern is a misrepair only relative to a decoder model:

- **Model A** — the admission classifier as built in the Verilog decoders
  (accept iff the syndrome is 0, a signed column, or a signed unit
  vector): seed6 accepts 0 of 69,184; the closed set accepts 0.
- **Model A+** — Model A extended to amplitudes e ∈ {±2, ±3}: both sets
  accept 0.
- **Model B** — a lookup decoder that also corrects pairs by syndrome:
  seed6 accepts 10 (the cross-weight aliases); the closed set accepts 0.

seed6's defect is a distinctness defect. Under the admission classifier
that was actually built, even seed6 refuses every weight-3 pattern; under
a pair-correcting lookup it would misrepair 10. The closed set is clean
under every model and fully distinct.
