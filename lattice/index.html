How this was measured — and what is only a label

Embedding of record: the SPATIAL MANIFOLD's sphere layout (build_manifold.py): a golden-angle Fibonacci spiral — for node index i (0–47, masks ascending), y = 1 − 2i/47, θ = GA·i with GA = π(3−√5) — with node order from the core record (core_compact.json). The measurement uses the exact formula, not the file's display rounding. Mapping rule: the record's unit direction becomes the point on the WGS84 ellipsoid at geodetic latitude asin(y), longitude atan2(z, x). The manifold's render radius is an appearance scale and is not part of any position. Pair classes are the GENESIS census classification (pairs.csv), verified identical to the core record's pair lists.

Labels are presentation. The class names (door, alias, never), the headings, and this page's arrangement were applied after the measurement was complete. The measurement itself is the raw pair data served with this page; the audit above runs on that data with the labels stripped, and it is the audit — not the labels — that the certificate attests.

Scope. The 48 positions stand on the embedding named above — the anchor set of record for the lattice. The tether layer is a separate, named layer: the Geodesic Network Registry's five baselines and the local anchor, with the spoken set of 2026-10-23 carried beside them. If the record receives another anchor set, this page re-anchors to it and the figures here are superseded in place — struck through, not erased.
