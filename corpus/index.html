RFF-1 — Refusal Frame Format: two-layer refusal
codec_c2 · {'file': 'RFF_SPEC.md', 'id': '12Ig0Yl8w1hNmF3mj7vX_-8NUVFnpDjwS'}
RFF-1 (Monsters Ink LLC, 2026-10-06; status: new matter, not filed) is a self-describing code format unifying two refusal layers: Layer 1, the C(r,N) common-bit refusal-code family (repair-or-refuse decoding), and Layer 2, labeled-lane admission on surviving frames (per-lane admit/refuse; surplus never crosses labels). Refusal propagates: a frame refused at Layer 1 never reaches Layer 2. Frame format: magic 0x52464631 ('RFF1'), r (1 byte), N (2 bytes, big-endian), L lane count (1 byte), payload N × float64, parity r × float64 (H × payload).
