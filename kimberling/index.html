An open problem, under measurement

The Kimberling Observatory

The Kimberling sequence (OEIS A007063) is built by a simple folding rule. It is proved that no value can appear twice. Whether every value appears at all is an open problem — a $300 prize, offered with the problem, stands unclaimed. This page is the state of the attack: what is proved, what is computed, and the search itself, running in your browser.

What is proved

Every value appears at most once. If the backward trace of a term ends at row i*, the term itself must be one of 3i*−4, 3i*−3, 3i*−2 — three consecutive values, and the triples for different rows never overlap. Each value therefore has exactly one possible starting position, and from that position exactly one possible path. Two different terms can never carry the same value.

No search can get stuck. From any target position, a valid predecessor always exists — proved three independent ways. A search can fail only by walking forever, never by hitting a wall.

A walk never loops back. Once a walk leaves its target shape it can never return to one, and every excursion on the negative side is provably finite. The one question computation cannot settle is whether every walk eventually arrives.

Run the search yourself

The search is deterministic: one rule, no choices. Pick any of the 591 targets the campaign verified first — or verify all 591 — and your browser walks the same path the campaign walked, step for step. The result is compared against the record of two independent implementations, written separately, which agreed on every target.

The walk will report here.

The remaining question

Surjectivity — whether every value appears — is exactly the question of whether every one of these walks terminates. That is still open, here and everywhere. Nothing on this page claims the problem is solved; the prize stands unclaimed. What this page shows is the evidence base: a complete proof of the half that is proved, and a computation that has never once gotten stuck.
