First crossing — the alias battery

Method: Variant A. For each set, every pair of columns and every triple — 1,128 pairs and 17,296 triples, under every sign pattern, 69,184 triple combinations in all — is summed into a syndrome. A syndrome that runs parallel to a single column is an alias: a multiple fault that a decoder would mistake for a single-column fault and wrongly “repair.” The battery counts them, exhaustively.
